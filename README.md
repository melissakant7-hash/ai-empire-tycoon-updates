# AI Training Licensing & Release Endpoint

Current Full Game version: **v10.7.4**.

## v10.7.4

- Upgrades tutorial narration to a more human voice mode.
- Automatically ranks available voices and strongly prefers Neural, Natural and Online voices over classic desktop TTS voices.
- German prioritizes high-quality German Microsoft Natural/Neural voices when available; English does the same for modern English Natural/Neural voices.
- The Windows launcher now prefers Microsoft Edge first to improve access to Windows Natural voices, with Chrome and Brave as fallbacks.
- Tutorial narration uses slightly slower, clearer pacing for a more human guided-tutorial feel.
- Keeps the Generation 2 hardware-bound **AITL2** license gate, Windows DPAPI-protected activation, signed live revocation checks and 24-hour offline grace period from v10.7.3.
- Keeps the sharp no-blur tutorial, one-time automatic tutorial start, complete German tutorial and broader German localization.

This public repository provides AI Training release metadata and live license revocation data. The paid Full Game package is **not distributed from this public repository**.

Public files contain no private signing seed, no content master key, and no playable Full Game package.
