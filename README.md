# AI Training Licensing & Release Endpoint

Current Full Game version: **v10.7.11**.

## v10.7.11

- Separates **customer demand** from **physical serving capacity**. A full datacenter fleet no longer stops a successful model from attracting additional customers.
- Strong new Language AI releases now create a longer multi-week/month adoption curve instead of jumping rapidly toward a fixed user target and then appearing hard-capped.
- Launch momentum scales with the new model's improvement over the player's previous models, its position versus the rival frontier, company brand/reputation and launch strategy.
- The market-growth ceiling for strong Language AI launches is substantially less restrictive, so frontier releases can continue expanding the company's addressable customer base instead of flattening around the previous artificial target.
- Datacenter utilization remains a strict physical **100% maximum**. When demand exceeds capacity, the extra customers become **paused / waitlisted** rather than disappearing.
- Only traffic that the fleet can actually serve generates normal Language AI subscription/API revenue and serving cost. Adding capacity can immediately convert accumulated waitlisted demand into active usage.
- Model serving cards now show **Potential customers**, **New demand / day**, and **Paused / waitlisted** customers so launch growth remains visible even while the fleet is full.
- Keeps the v10.7.10 100% serving ceiling, unserved-demand economics, Cybersecurity AI model-type selector fix and global interaction-stability fix for missed clicks/hover flicker.
- Keeps the Sandbox manual-serving controls and physical-serving baseline fix, meaningful model optimization generations, stronger Custom AI Silicon, visible rival cyber damage and rebalanced difficulties.
- Keeps independent Graphics research, Unlock All Research, replacement-license fix, hardware-bound AITL2 licensing, live validation, human-voice tutorial narration, shared browser profile and no-blur tutorial.
